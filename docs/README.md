## 历史资料

`archive/` 下的内容按用途分层保存：

- `archive/handoffs/`：已结束会话的交接记录。
- `archive/designs/`：已实施或已替代的独立设计。
- `archive/superpowers/`：历史实现计划和规格。
- `archive/recovery/`：源代码恢复样本、诊断报告和原始分析证据。

历史资料仅用于追溯；以当前 `app/`、`tests/`、根目录 README 和本目录“当前文档”为准。
