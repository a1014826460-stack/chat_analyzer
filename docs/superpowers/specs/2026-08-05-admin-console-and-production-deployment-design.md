# 管理后台与生产部署设计

## 目标

将集中 FastAPI 服务部署到 `207.56.2.71:8080`，桌面客户端固定连接
`http://207.56.2.71:8080`；新增可管理软件用户、授权、设备、策略、订单、日志
及服务状态的 Web 管理后台。

## 访问与部署

- 生产服务目录为 `/opt/startrace`，由 Docker Compose 运行 PostgreSQL、Redis、迁移、
  FastAPI API 和 worker。
- API 服务监听 `0.0.0.0:8080`；PostgreSQL 与 Redis 仅保留 Docker 内部网络。
- 管理后台入口为 `/admin`；API 与后台同源，暂时使用 HTTP。迁移 HTTPS 时在前方增加
  Caddy 或 Nginx，保留域名/路由，并将 Cookie 的 `Secure` 属性开启。
- 服务器 `.env` 仅保存在服务器，包含数据库密码、JWT 密钥、Fernet 密钥、初始引导令牌
  与 AI 配置；不得提交或输出到日志。

## 客户端连接

- 源码开发模式默认 API 根地址固定为 `http://207.56.2.71:8080`，不从环境变量或用户
  设置读取替代地址。
- 打包程序继续由构建过程嵌入同一地址；构建脚本拒绝空地址或非该生产地址。
- 现有机器码和授权码交换流程不变，仍经 `/v1/auth/session` 取得用户 JWT。

## 管理员身份和首次引导

- 管理员使用用户名、密码和 TOTP（RFC 6238）登录。首个用户名默认 `admin`，首次
  初始化页面允许修改该用户名。
- 服务器启动时仅在尚无管理员且 `ADMIN_BOOTSTRAP_TOKEN` 匹配时开放 `/admin/setup`。
  初始化收集管理员用户名、强密码和 TOTP 验证码，生成二维码/密钥并创建管理员。
- 成功初始化后将引导令牌哈希持久化标记为已消费；后续请求即使携带同一令牌也不能再次
  初始化。管理员 Cookie 会话为 HttpOnly、SameSite=Lax，HTTP 阶段 `Secure=False`，
  HTTPS 阶段由环境变量切换为 `Secure=True`。
- 登录实行速率限制；密码使用 Argon2id 哈希；TOTP 密钥以现有 Fernet 服务端密钥加密。
  退出、改密、重新绑定 TOTP 及管理员敏感操作均写入管理员审计事件。

## 管理后台结构

- 固定左侧导航：总览、用户管理、激活码、策略与订单、运行日志、系统设置。
- 所有已登录页面顶部固定指标条：在线用户数、当日 API 请求数、异常数、API 可用状态。
  Worker、Redis、PostgreSQL 的状态在总览与系统设置中呈现。
- 页面使用 FastAPI Jinja2 模板和同源轻量 JavaScript，数据经受管理员会话保护的
  `/v1/admin/*` API 获取；不引入独立 SPA 构建链路。

## 管理功能

- 用户：按 ID、激活码状态和机器码搜索；显示授权状态、到期时间、已用/上限设备数、
  最近活动；可禁用/恢复授权以及撤销指定或全部设备会话。
- 激活码：默认批量数 `1`、有效期 `1` 天、最大设备 `2`；支持生成、复制明文结果、
  搜索、撤销和延期。明文仅在生成响应中出现，数据库只保存哈希。
- 策略与订单：按用户、站点、时间与状态查看策略配置和订单/发送尝试；不展示 WSS
  `user_sig` 等敏感凭据。
- 运行日志：按用户、级别、分类、站点与时间检索，展示脱敏后的事件及错误摘要。
- 系统：显示 API/worker/Redis/PostgreSQL 健康、最近请求和异常；记录管理员审计日志。

## 数据与接口

- 新增 `admin_users`、`admin_sessions`、`admin_audit_events`、`service_heartbeats` 与
  `bootstrap_state` 表；生产迁移在原有 Alembic head 后执行。
- 管理员 API 使用 Cookie 会话依赖，桌面用户 JWT 不能访问。旧 `X-Admin-Token` 管理
  接口在管理员体系完成后移除或改为管理员会话保护。
- API 中间件记录请求计数和错误计数；API 与 worker 定时上报心跳，并以 Redis 的短 TTL
  状态区分在线和离线。

## 验收标准

- `http://207.56.2.71:8080/health/ready` 返回 `200`，Docker API 和 worker 均运行。
- 首次访问 `/admin/setup` 只有正确的一次性引导令牌可进入；创建 `admin`、密码和 TOTP
  后，令牌不能重复使用。
- 管理员必须同时通过密码和 TOTP 才能访问 `/admin` 或 `/v1/admin/*`。
- 每个后台页面都有固定指标条；用户、激活码、设备会话、策略订单、日志、服务状态和
  审计功能均可操作或查看。
- 默认生成一个有效期一天、最大两设备的激活码；撤销/延期及时影响桌面授权。
- 源码和打包客户端仅连接 `http://207.56.2.71:8080`，本地配置无法覆盖。
