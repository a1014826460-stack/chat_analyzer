# 一级模块手风琴与开奖降级设计

**目标：** 将左侧四个一级模块改为状态保持的手风琴，并在当前期开奖源暂不可用时保持界面可用且自动重试。

## 一级模块手风琴

折叠边界仅为“线路选择”“账号与数据源”“屏蔽名单”“自动下注”四个一级模块；删除此前的“基础配置”“高级配置”“操作”子项折叠。每个模块的全部既有控件置于一个永久内容容器内，默认仅展开线路选择。点击任意模块标题会展开该模块并收起其余三个模块。

标题使用轻量圆角卡片：主题主色渐变、圆角边框、图标/标题、辅助摘要和可旋转箭头。悬浮时提高亮度和边框对比度，按下时缩小阴影；箭头旋转与内容高度均使用 Qt 属性动画。隐藏内容不会销毁控件，输入、选择、分页日志及运行状态保持不变。

## 当前期开奖暂不可用

桌面分别拉取每条线路。单条请求失败（包括 API 503）不再中断全部线路卡片刷新：保留该线路最后成功的 `DrawInfo`，设置线路状态为暂不可用，并进入既有校准/刷新周期重试。没有历史数据时保留空卡片而不抛出界面线程异常。API 仍返回 503，客户端不得回退访问第三方开奖源。

## 验收

- 四个一级模块是唯一的折叠标题；任何模块内不再显示基础/高级/操作折叠标题。
- 同一时刻仅一个一级模块展开；默认展开线路选择；折叠前后控件对象和值保持一致。
- 标题具备主题色圆角、悬浮/按下反馈和箭头动画。
- 任意一条 `/current` 返回 503 时，其他线路正常渲染，失败线路保留旧值并显示可读状态，无未处理 future 异常。
