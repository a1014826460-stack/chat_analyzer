# 五个一级模块手风琴视觉优化设计

## 目标

将左侧的“线路选择”“账号与数据源”“筛选条件”“屏蔽名单”“自动下注”统一为五个互斥展开的一级模块，减少折叠标题之间的空白，并恢复清晰的模块内容卡片层级。

## 交互与视觉

- 左侧模块布局间距由 10px 降为 3px；一级模块标题之间紧凑排列。
- 每个 `CollapsibleSection` 的内容容器采用白色圆角卡片、主题浅色边框和轻量阴影，与页面背景区分。
- 标题继续保留主题渐变、圆角、悬浮/按下反馈及箭头、内容高度动画。
- “筛选条件”迁移到 `filter_module_section`，与其余四个模块共同受 `ModuleAccordion` 管理。
- 默认仅“线路选择”展开；展开任一模块时收起其余四个。折叠仅隐藏内容，不重建任何控件，筛选时间、群组选择、输入和运行状态不变。

## 验收标准

- 左侧手风琴包含五个模块，且筛选条件不再使用独立 `QGroupBox`。
- 相邻一级模块布局间距为 3px，内容容器样式包含白色背景与圆角边框。
- 五模块始终互斥展开，默认线路选择展开。
- 现有自动下注、线路卡片和筛选控件测试保持通过。
